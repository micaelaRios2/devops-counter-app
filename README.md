# 🚀 DevOps Multi-Container Counter App

Proyecto Full-Stack demostrativo con arquitectura de microservicios usando **Node.js/Express**, **Redis** 
y **Docker Compose**.

## 🛠️ Tecnologías Utilizadas
* **Node.js & Express**: Backend API.
* **Redis**: Base de datos clave-valor en memoria para conteo de visitas.
* **Docker & Docker Compose**: Containerización y orquestación.
* **Docker Hub**: Registro remoto para distribución de imágenes.

## 🚀 Cómo ejecutar localmente

```bash
git clone 
[https://github.com/micaelaRios2/devops-counter-app.git](https://github.com/TU_USUARIO_GITHUB/devops-counter-app.git)
cd devops-counter-app
docker compose up -d
